Six tasks, verified steps

Guides

Every guide starts from a real task and uses the commands or tools that exist. The write steps need your approval.

> Download a semester

  1. See your courses

    Filter by year and semester. study_year_source says where the year comes from: the description or another course with the same subject.

    ase-moodle courses --year 3 --sem 1

  2. Download

    Files, pages, links, assignments, forums, quizzes and grades land in the given folder. --shallow takes only the structure and the files.

    ase-moodle download --year 3 --sem 1 --out D:\Materiale

  3. Read the summary

    _rezumat.json holds the errors and warnings. A course without files is normal: many have only forums or links.

  4. Run again if something is missing

    Files of the same size are skipped, so a second run downloads only what is missing. For a single course, pass --course ID instead of the year and semester filters.

> What is in the folder

Diagram: the ~/ASE-Moodle folder holds one folder per course, with index.md, teme.md, forumuri/, quizuri.md, note.md, linkuri.txt and _raw/*.json.

> See what is due

  1. Deadlines

    The next days' deadlines, in order, with the course, the type and the date.

    ase-moodle deadlines --days 14

  2. New notifications

    Unread only, with the total unread count in the answer.

    ase-moodle notifications --unread

  3. Open assignments

    The assignment list, with deadlines and submission type.

    ase-moodle assignments

> Prepare and submit an assignment

  1. Read the requirement and the state

    assignment_status returns drafts_enabled, the submitted files or text, the grade and the feedback.

    ase-moodle assignment 201

  2. Check whether the assignment has drafts

    With drafts, saving keeps the file as a draft. Without drafts, saving sends at once; the package refuses, so nothing goes out by mistake.

  3. Prepare the file or the text

    The file must exist locally. For text, use --text, --file or a pipe.

  4. Save the draft

    Without --submit, it stays a draft, if the assignment has drafts.

    ase-moodle submit 201 D:\teme\raport.pdf --yes

  5. Submit for grading, after checking

    --submit makes the final submission. In MCP, the same rule: submit_for_grading=true and confirm=true.

    ase-moodle submit 201 D:\teme\raport.pdf --submit --yes

> Reply on a forum

  1. Find the forum

    The course forums, including the announcements forum.

    ase-moodle forums --course 73445

  2. Read the discussion

    The forum's discussions, then the discussion's posts, with text and attachments.

    ase-moodle forum 12
ase-moodle discussion 34

  3. Write the reply and show it

    Prepare the subject and the text. Check exactly what goes out before confirming.

  4. Send

    --yes confirms the write. Approval for one reply does not cover the next.

    ase-moodle reply 56 --subject "Intrebare laborator" --text "..." --yes

> Answer a quiz

  1. See the attempts

    The previous attempts, with their state and grade.

    ase-moodle quiz-attempts 77

  2. Start an attempt

    Every attempt counts against Moodle's limit. --force-new asks for a new one.

    ase-moodle quiz-start 77 --yes

  3. Read the questions

    Every field has a name; use exactly that name as the answer key.

    ase-moodle quiz-questions 501

  4. Save the answers without submitting

    Without --finish, the answers are saved and the attempt stays open.

    ase-moodle quiz-answer 501 --answers '{"q1:1_answer": "2"}' --yes

  5. Finish, after a second approval

    --finish is irreversible. The server rejects field names that do not exist in the attempt.

    ase-moodle quiz-answer 501 --answers '{"q1:1_answer": "2"}' --finish --yes

  6. See the result

    The review appears once Moodle allows it: questions, answers and marks.

    ase-moodle quiz-review 501

> Find a course

  1. Filter the list

    By year, semester, academic year, type or text in the name.

    ase-moodle courses --tip LABORATOR --search retele

  2. Open the structure

    The course sections, modules and files, as raw Moodle JSON.

    ase-moodle outline 73445

Academic integrity

Check the course rules before using quizzes. Many courses forbid automated help or outsourcing answers. The student is responsible for what is submitted.
