Install

You need Python 3.10+ and a BL@ASE account. Pick one path: pipx, npm, the script in the repo or pip. The result is the same: the ase-moodle and ase-moodle-mcp commands on PATH. The ase-moodle install page explains each path in turn, and at the end you have an MCP server for Moodle ready to start.

> Path 1: pipx (recommended)

  1. Install pipx, once

    pipx installs Python applications in isolated environments and puts them on PATH.

    python -m pip install --user pipx

  2. Install ase-moodle

    The package comes straight from GitHub.

    pipx install git+https://github.com/FiredMosquito831/ase-moodle-mcp.git

  3. Sign in, configure, verify

    Login opens the browser once. install writes the clients' configuration, and doctor says what is missing.

    ase-moodle login
ase-moodle install
ase-moodle doctor

> Path 2: npm

  1. Install the launcher

    The npm package installs the Python package through pipx. The first run takes a few minutes, and npm does not show progress.

    npm install -g ase-moodle-mcp

  2. See the progress, if you want

    The same install, with the script's messages visible.

    npm install -g --foreground-scripts ase-moodle-mcp

  3. Sign in and configure

    The commands are the same as with pipx.

    ase-moodle login
ase-moodle install
ase-moodle doctor

> Path 3: the script in the repo

The scripts do everything from a clone: install the package, install Chromium on Linux and macOS, sign in, configure the CLIs and run doctor.

> Path 4: pip directly

Without pipx, in the global Python or in a venv. For development, -e makes code changes active immediately.

> For one folder only

ase-moodle install --scope project writes the configuration only in the folder you run it from. The project scope does not apply in subfolders. Antigravity stays global: it has no project scope.

> What each command does

CommandWhat it does
ase-moodle loginopens the browser; you sign in with Google once, and the token is saved in the keychain
ase-moodle installadds the plugin to the CLIs it finds: Claude Code, Codex, opencode, Antigravity
ase-moodle doctorchecks the installation, the token, the MCP processes and the Moodle functions; changes nothing
ase-moodle updatebrings the latest marketplace version; restart Claude Code afterwards
ase-moodle uninstallremoves the configuration from the chosen CLIs; does not delete the Python package

> Update

With pipx, pipx upgrade does not bring new code from GitHub. Use --force, then ase-moodle update, and restart Claude Code.

> Uninstall

The package has several parts, installed separately. Run the steps that use ase-moodle first, then delete the package.

Without a global install

After npm, you can run npx ase-moodle-mcp <command>. For MCP clients use the global install, so a fixed ase-moodle-mcp command exists on PATH.

> Check after installing

auth-status says whether you are signed in, courses does a real read, and doctor shows each platform's state. Exit code 3 means doctor found a problem.
