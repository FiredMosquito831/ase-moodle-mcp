MCP tools

The ase-moodle-mcp server exposes the tools below over stdio. The table is generated from the real definitions: the names, parameters, types and annotations come from the code.

> How to read the table

Every tool has a type: read (changes nothing), write (changes the account and needs confirm=true) or local (works on your machine). Parameters show the name, the type and the default value, when there is one.

Tools that return lists answer with {"count": n, "items": [...]}. Moodle errors arrive as tool errors, with the original message.

> Rules

Writes need confirm=true. Without it, the server returns an error and does nothing. Submissions to assignments without drafts are refused, except with allow_direct=true.

Prompts are ready-made flows the client can offer as commands. Resources are readable context: your profile and the deadlines for the next 14 days.
