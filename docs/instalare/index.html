Instalare

Ai nevoie de Python 3.10+ și de un cont BL@ASE. Alege o variantă: pipx, npm, scriptul din repo sau pip. Rezultatul e același: comenzile ase-moodle și ase-moodle-mcp în PATH. Pagina de instalare ase-moodle explică fiecare variantă în parte, iar la final ai un server MCP pentru Moodle gata de pornit.

> Varianta 1: pipx (recomandată)

  1. Instalează pipx, o singură dată

    pipx instalează aplicațiile Python în medii izolate și le pune în PATH.

    python -m pip install --user pipx

  2. Instalează ase-moodle

    Pachetul vine direct din GitHub.

    pipx install git+https://github.com/FiredMosquito831/ase-moodle-mcp.git

  3. Loghează-te, configurează, verifică

    Login-ul deschide browserul o singură dată. install scrie configurația clienților, iar doctor spune ce lipsește.

    ase-moodle login
ase-moodle install
ase-moodle doctor

> Varianta 2: npm

  1. Instalează launcherul

    Pachetul npm instalează pachetul Python prin pipx. La prima rulare durează câteva minute, iar npm nu afișează progresul.

    npm install -g ase-moodle-mcp

  2. Vezi progresul, dacă vrei

    Aceeași instalare, cu mesajele scriptului vizibile.

    npm install -g --foreground-scripts ase-moodle-mcp

  3. Loghează-te și configurează

    Comenzile sunt aceleași ca la pipx.

    ase-moodle login
ase-moodle install
ase-moodle doctor

> Varianta 3: scriptul din repo

Scripturile fac tot din clonă: instalează pachetul, instalează Chromium pe Linux și macOS, te loghează, configurează CLI-urile și rulează doctor.

> Varianta 4: pip direct

Fără pipx, în Python-ul global sau într-un venv. Pentru dezvoltare, -e face modificările din cod active imediat.

> Doar pentru un folder

ase-moodle install --scope project scrie configurația doar în folderul de unde rulezi comanda. Scope-ul de proiect nu se aplică în subfoldere. Antigravity rămâne global: nu are scope de proiect.

> Ce face fiecare comandă

ComandăCe face
ase-moodle logindeschide browserul; te loghezi cu Google o singură dată, iar tokenul se salvează în seif
ase-moodle installadaugă pluginul în CLI-urile găsite: Claude Code, Codex, opencode, Antigravity
ase-moodle doctorverifică instalarea, tokenul, procesele MCP și funcțiile Moodle; nu modifică nimic
ase-moodle updateaduce ultima versiune din marketplace; repornește Claude Code după
ase-moodle uninstallscoate configurarea din CLI-urile alese; nu șterge pachetul Python

> Actualizare

Cu pipx, pipx upgrade nu aduce codul nou din GitHub. Folosește --force, apoi ase-moodle update și repornește Claude Code.

> Dezinstalare

Pachetul are mai multe părți, instalate separat. Rulează întâi pașii care folosesc ase-moodle, apoi șterge pachetul.

Fără instalare globală

După npm, poți rula npx ase-moodle-mcp <comandă>. Pentru clienții MCP folosește instalarea globală, ca să existe o comandă fixă ase-moodle-mcp în PATH.

> Verificare după instalare

auth-status spune dacă ești logat, courses face o citire reală, iar doctor arată starea fiecărei platforme. Codul de ieșire 3 înseamnă că doctor a găsit o problemă.
