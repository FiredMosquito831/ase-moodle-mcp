Install in three commands

You need Python 3.10+ and pipx. The same commands work on Windows, Linux and macOS.

  1. Install the package

    Pipx installs it in an isolated environment, without touching your Python.

    pipx install git+https://github.com/FiredMosquito831/ase-moodle-mcp.git

  2. Log in to Moodle

    The browser opens. Sign in with Google once. The token is stored in the Credential Manager, not in plain text.

    ase-moodle login

  3. Add the plugin to your agents

    The plugin is added to Claude Code, Codex, opencode and Antigravity, for the whole machine.

    ase-moodle install

Check with ase-moodle doctor. For one folder only: ase-moodle install claude --scope project, run from that folder. Update: pipx install --force git+…, then ase-moodle update. Full steps are in docs/INSTALL.md.

What it can do

MCP tools, prompts and resources that act on your account, with confirmation for every write.

📚

Courses and materials

List courses by year, semester and type (lecture, seminar, lab). Download materials into week folders.

📝

Assignments

Read tasks, deadlines and submission status. Submit files as a draft or final, after your approval.

💬

Forums

Read discussions, reply and open new threads, only after confirmation.

🧠

Quizzes

Read questions, save answers and submit the attempt only after a second approval.

🔔

Notifications and deadlines

See what is new and what is due in the coming days. Mark notifications as read.

🔧

Any Moodle function

Access to the Web Service functions of the mobile service, with the same confirmation rules.

Want the server in every subfolder of a large folder? Use global scope. The project plugin applies only when you start the client in that exact folder. Details: docs/MCP.md.

Safety

The package works with your account. The rules below are enforced by the server, not only by the agent.

  • Writes need confirmation. Submitting, replying on a forum and submitting a quiz require confirm=true. Without it, nothing happens.
  • Draft guard. For an assignment without drafts, saving would send the file at once. The server refuses unless the student explicitly asks for it.
  • Token in the Credential Manager. It is never printed or passed through clients. Your Google password is never stored.
