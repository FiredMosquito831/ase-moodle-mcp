ase-moodle: Moodle BL@ASE for AI agents

An MCP server, CLI and plugin that connects AI agents to your BL@ASE Moodle account (online.ase.ro): courses, materials, assignments, forums, grades, quizzes, notifications and deadlines. Works in Claude Code, Codex, opencode and Google Antigravity.

Source code on GitHub Installation Command reference Safety

What it can do

  • List courses by study year, semester and type (lecture, seminar, lab).
  • Download a year's or a course's materials in parallel, organised into week folders.
  • Read assignments, submission status, feedback and deadlines.
  • Submit assignments, reply on forums and open discussions, only after your confirmation.
  • Read and answer quizzes, with your approval before the final submission.
  • Show notifications and upcoming deadlines.

Install in three commands

You need Python 3.10+ and pipx. The same commands work on Windows, Linux and macOS.

pipx install git+https://github.com/FiredMosquito831/ase-moodle-mcp.git
ase-moodle login
ase-moodle install
  1. pipx install: installs ase-moodle in an isolated environment, without touching your Python.
  2. ase-moodle login: opens the browser. You sign in with Google once.
  3. ase-moodle install: adds the plugin to Claude Code, Codex, opencode and Antigravity.

Check with ase-moodle doctor. Step-by-step details and alternatives are in docs/INSTALL.md.
