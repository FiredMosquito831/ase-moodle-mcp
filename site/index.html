ase-moodle: Moodle BL@ASE pentru agenți AI

English · Română

Server MCP, CLI și plugin care dau agenților AI acces la contul tău de Moodle BL@ASE (online.ase.ro): cursuri, materiale, teme, forumuri, note, quizuri, notificări și termene. Funcționează în Claude Code, Codex, opencode și Google Antigravity.

English: an MCP server, CLI and plugin that connects AI agents to your BL@ASE Moodle account (online.ase.ro): courses, assignments, forums, grades, quizzes, notifications and deadlines.

Cod sursă pe GitHub Instalare Referința comenzilor Siguranță

Ce poate face

  • Listează cursurile pe an de studiu, semestru și tip (CURS, SEMINAR, LABORATOR).
  • Descarcă materialele unui an sau ale unui curs, în paralel, în foldere organizate pe săptămâni.
  • Citește temele, starea trimiterii, feedbackul și termenele.
  • Trimite teme, răspunde pe forum și deschide discuții, doar după confirmare.
  • Citește și răspunde la quizuri, cu aprobare înainte de trimiterea finală.
  • Arată notificările și termenele apropiate.

Instalare în trei comenzi

Ai nevoie de Python 3.10+ și de pipx. Funcționează la fel pe Windows, Linux și macOS.

pipx install git+https://github.com/FiredMosquito831/ase-moodle-mcp.git
ase-moodle login
ase-moodle install
  1. pipx install: instalează ase-moodle izolat, fără să strice Python-ul tău.
  2. ase-moodle login: deschide browserul. Te loghezi cu Google o singură dată.
  3. ase-moodle install: adaugă pluginul în Claude Code, Codex, opencode și Antigravity.

Verifici cu ase-moodle doctor. Pașii detaliați și variantele sunt în docs/INSTALL.md.
