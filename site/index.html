Instalare în trei comenzi

Ai nevoie de Python 3.10+ și de pipx. Aceleași comenzi merg pe Windows, Linux și macOS.

  1. Instalezi pachetul

    Pipx îl pune izolat, fără să strice Python-ul tău.

    pipx install git+https://github.com/FiredMosquito831/ase-moodle-mcp.git

  2. Te loghezi în Moodle

    Se deschide browserul. Te loghezi cu Google o singură dată. Tokenul se salvează în Credential Manager, nu în text clar.

    ase-moodle login

  3. Adaugi pluginul în agenți

    Pluginul ajunge în Claude Code, Codex, opencode și Antigravity, pentru tot calculatorul.

    ase-moodle install

Ai Node.js? npm install -g ase-moodle-mcp face și primul pas, instalând și pachetul Python prin pipx. Fără instalare globală: npx ase-moodle-mcp auth-status.

Verifici cu ase-moodle doctor. Doar pentru un folder: ase-moodle install claude --scope project, rulat din acel folder. Actualizare: pipx install --force git+…, apoi ase-moodle update. Dezinstalare: ase-moodle uninstall, apoi pipx uninstall ase-moodle (sau npm uninstall -g ase-moodle-mcp). Pașii detaliați sunt în docs/INSTALL.md.

Ce poate face

Unelte, prompturi și resurse pentru agenți, toate pe contul tău, cu confirmare pentru orice scriere.

📚

Cursuri și materiale

Listează cursurile pe an, semestru și tip (CURS, SEMINAR, LABORATOR). Descarcă materialele în foldere pe săptămâni.

📝

Teme

Citește sarcinile, termenele și starea trimiterii. Trimite fișiere ca ciornă sau final, după aprobarea ta.

💬

Forumuri

Citește discuțiile, răspunde și deschide discuții noi, doar după confirmare.

🧠

Quizuri

Citește întrebările, salvează răspunsurile și trimite încercarea doar după a doua aprobare.

🔔

Notificări și termene

Vezi ce e nou și ce are termen în zilele următoare. Marchezi notificările ca citite.

🔧

Orice funcție Moodle

Acces la funcțiile Web Service ale serviciului mobil, cu aceleași reguli de confirmare.

Vrei serverul în toate subfolderele unui folder mare? Folosește scope global. Pluginul de proiect se aplică doar când pornești clientul din folderul exact. Detalii: docs/MCP.md.

Siguranță

Pachetul lucrează cu contul tău. Regulile de mai jos sunt aplicate de server, nu doar de agent.

  • Scrierile cer confirmare. Trimiterea, răspunsul pe forum și quizul cer confirm=true. Fără el, nu se întâmplă nimic.
  • Garda pentru ciorne. La o temă fără ciorne, salvarea ar trimite fișierul direct. Serverul refuză, dacă nu cere explicit studentul.
  • Token în Credential Manager. Nu îl afișează și nu îl trimite prin clienți. Parola Google nu e stocată niciodată.
